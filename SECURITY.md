# Security policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues.

Use **Report a vulnerability** in the Security tab of this GitHub repository. This creates a private security advisory that only the repository maintainers can access while the report is investigated.

Include the affected version, operating system, steps to reproduce, impact, and any suggested mitigation. Please avoid including personal project data or secrets in the report.

## Trusted downloads

The Wuniq desktop app is free. Download it only through the official links published at [wuniq.com](https://www.wuniq.com). Third-party mirrors and repackaged installers are not authorized or supported.
